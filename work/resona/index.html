Transcript

This is a private dictation app. Every word is transcribed on your own computer, so the recording never has to leave it.

You can record from the microphone, choose a file, or paste a link to a video. Here, I'm choosing a short audio clip from my computer.

It transcribes on the graphics card, and the app tells you so: no network.

So I checked. While it was transcribing, I sampled every network connection held by the app and its web view. The app's own process opened none. The one connection came from Microsoft's web view runtime, the browser engine that draws the interface, and it went to a Microsoft address.

Every word gets its own timestamp, and the whole transcript is editable. Whisper heard one name wrong, so I fix it right in place.

Then it exports to plain text, subtitles, Word, PDF, or one zip file of everything.

One Rust core, four backends, and three desktop platforms. I built it with Jimmy Ong.

01What it is

Desktop dictation, live and from files, that runs entirely on the machine. The privacy claim is checkable by anyone in ten seconds: disconnect the network and it keeps transcribing.

02How it works

Dictation is the one input that is inherently sensitive.

  • Microphone capture through cpal, energy-based voice-activity detection, then incremental Whisper, so text appears as you speak.
  • One Rust core and one codebase for CUDA, Vulkan, Metal and CPU; Tauri 2 builds every target from the same source.
  • Tier gating lives in the Rust core with Ed25519-signed licences, so an entitlement check is not a frontend suggestion.

03The hard part

Making the privacy claim testable rather than promised.

  • Mainstream dictation streams audio to someone else's server, with a privacy policy as the only thing between the recording and a training set.
  • On first run it profiles the machine and recommends a model size, instead of making the user guess between tiny and large.
  • A security pass found and fixed an SSRF path and an unsafe export (SEC-001, SEC-002).

04What it doesn't do

One defect kept visible on purpose.

  • The hardware probe reports 32041 GB RAM on a 32 GB machine: megabytes labelled as gigabytes. It stays documented rather than cropped out, because it is the class of bug that survives by looking like a big impressive number.
